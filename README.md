# Physical AI — практика PandaPickCube

Практика Яндекс Практикума, выполненная Димой Савосиным 7 ноября 2026 года.

Обучение PPO в Google Colab на T4, запуск модели на CPU в Docker Desktop под Windows, сравнение чекпоинтов и проверка устойчивости к позиции куба и шуму наблюдений.
